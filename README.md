Introduction

An Algorithm is a step-by-step procedure or set of instructions used to solve a specific problem or perform a particular task efficiently. Algorithms are the foundation of computer programming and software development.

They help computers process data, make decisions, automate tasks, and optimize performance in various applications such as artificial intelligence, web development, cybersecurity, and data science.

Characteristics of an Algorithm
1. Input

An algorithm accepts zero or more inputs.

2. Output

It produces at least one result or output.

3. Definiteness

Each step must be clear and unambiguous.

4. Finiteness

The algorithm must terminate after a finite number of steps.

5. Efficiency

It should solve problems using minimum time and memory.

Types of Algorithms
1. Searching Algorithms

Used to find specific data from a dataset.

Examples:
Linear Search
Binary Search
2. Sorting Algorithms

Used to arrange data in a specific order.

Examples:
Bubble Sort
Selection Sort
Merge Sort
Quick Sort
3. Recursive Algorithms

Algorithms that solve problems by calling themselves.

Examples:
Factorial
Fibonacci Series
4. Graph Algorithms

Used in network and pathfinding systems.

Examples:
BFS (Breadth First Search)
DFS (Depth First Search)
Dijkstra Algorithm
5. Dynamic Programming Algorithms

Used for optimization problems.

Examples:
Knapsack Problem
Longest Common Subsequence
Common Algorithm Complexities
Complexity	Description
O(1)	Constant Time
O(log n)	Logarithmic Time
O(n)	Linear Time
O(n log n)	Linearithmic Time
O(n²)	Quadratic Time
